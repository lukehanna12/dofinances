Apple HIG Reader

          

            

              

                
 INDEPENDENT SOFTWARE PROJECT / GOOGLE APPS SCRIPT

                
Design documentation, made programmatically readable.

                
A read-only API I built with Google Apps Script that turns Apple's live Human Interface Guidelines into discoverable topics, searchable results, and paginated Markdown—ready for developer tools and automated workflows.

                

                  Explore the integration 
                  Original documentation 
                

              

              

                
 HIG READER / REQUEST EXAMPLEv1.1.0

                
POST/execJSON

                
{
  "action": "read",
  "slug": "materials",
  "offset": 0,
  "chunkSize": 12000
}

                

                
STRUCTURED RESPONSE
Markdown content✓
Source & media references✓
Continuation offset✓

                
Illustrative contract, not a live API response. Authentication is supplied server-side.

              

            

            

              
PLATFORMGoogle Apps Script

              
RELEASEv1.1.0

              
INTERFACEHTTPS · JSON

              
OPERATIONS3 read-only

            

            

              
01 / API CAPABILITIES
Find it. Search it. Read it.
Three focused operations make Apple's HIG practical to consume without maintaining a separate documentation mirror.

              

                

                  01List topics hig.listBrowse available topics with pagination
                  
Discover the current topic inventory in bounded batches.
{"action":"list","offset":0,"limit":50}

                

                

                  02Search documentation hig.searchLocate a topic by name, slug, or section
                  
Find relevant guidance before retrieving an article.
{"action":"search","query":"materials","limit":20}

                

                

                  03Read articles hig.readRetrieve Markdown in resumable chunks
                  
Retrieve Markdown with source links, media references, warnings, and continuation information.
{"action":"read","slug":"materials","offset":0,"chunkSize":12000}

                

              

            

            

              
02 / SYSTEM DESIGN
A small service, not a mirror.
Live documentation stays at the source. The application handles retrieval and formatting; a separate private integration makes its operations available to Colosseum.

              

                
SOURCEApple HIG / DocC
Original design documentation

                →
                
APPLICATIONGoogle Apps Script
On-demand JSON and Markdown delivery

                →
                
INTEGRATIONColosseum MCP
Owner-only list, search, and read tools

              

              

                
Live, not duplicated
Fetch articles on demand; no bulk HIG copy in application storage.

                
Complete context
Preserve original source links, image and video references, and chunk continuation metadata.

                
Secret stays private
The Colosseum adapter injects credentials server-side and restricts upstream redirects; the browser never receives the token.

              

            

            

              Built with Google Apps Script · Integrated with Colosseum as catalog item 0001cd
              Cloud integration is read-only; live token-authenticated availability is not asserted here.
