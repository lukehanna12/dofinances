LaTeXceL

Function reference

Start here

Open Equation Studio preview. Excel functions use LATEXCEL.NAME; Google Sheets functions use LATEXCEL_NAME. The functions return LaTeX strings and do not calculate the numerical expression. Use the pane to render SVG or PNG. Explicit external image formulas send expressions to CodeCogs.

Excel: download the add-in manifest, then sideload it in a supported Excel installation. Google Sheets: install the Editor add-on from its Apps Script project or use the packaged development files.

Typography

RM

Roman math font

=LATEXCEL.RM("WT")
=LATEXCEL_RM("WT")
\mathrm{WT}

FONT

Choose a math font: rm, it, bf, bb, cal, sf, tt, frak

=LATEXCEL.FONT("R","bb")
=LATEXCEL_FONT("R","bb")
\mathbb{R}

TEXT

Escape literal text for a math expression

=LATEXCEL.TEXT("sample & data")
=LATEXCEL_TEXT("sample & data")
\text{sample \& data}

Scripts

SUB

Attach a subscript

=LATEXCEL.SUB("x","i")
=LATEXCEL_SUB("x","i")

SUPER

Attach a superscript

=LATEXCEL.SUPER("x","2")
=LATEXCEL_SUPER("x","2")

SCRIPTS

Attach subscript and superscript; blanks omitted

=LATEXCEL.SCRIPTS("x","i","2")
=LATEXCEL_SCRIPTS("x","i","2")

Composition

https://latex.codecogs.com/png.image?\dpi{180}\smallx

URL

CodeCogs PNG URL at chosen DPI (72 to 600); no network call

=LATEXCEL.URL("x","180")
=LATEXCEL_URL("x","180")
https://latex.codecogs.com/png.image?\dpi{180}\smallx

Privacy

No account, telemetry or expression-upload service is built into LaTeXceL. The Excel client loads Office.js from Microsoft. The Google Sheets client loads pinned MathJax JavaScript from jsDelivr. Equations are rendered in the browser. Explicit CodeCogs IMAGE formulas are external requests. Do not use them for confidential expressions.
