# Website-specific integration gate

The universal native proof remains intact in the Oracle. The previous release gate is archived as NATIVE_RELEASE_CRITERIA.json. The website release now requires exact current-site coverage, coordinate separation, preservation of current appearance/interaction, comparative quality and performance. It does not require universal Apple parameter selection, signed-half semantics outside the site's source formats, or active-display EDR reconstruction. The public renderer must not be switched on by default until all six gates have evidence. The authenticated /app is a distinct renderer and is not silently changed.
