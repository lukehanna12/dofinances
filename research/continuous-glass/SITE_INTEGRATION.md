# Website-specific integration gate

The universal native proof remains intact in the Oracle. The previous release gate is archived as NATIVE_RELEASE_CRITERIA.json. The website release now requires exact current-site coverage, coordinate separation, preservation of current appearance/interaction, comparative quality and performance. It does not require universal Apple parameter selection, signed-half semantics outside the site's source formats, or active-display EDR reconstruction. The public renderer must not be switched on by default until all six gates have evidence. The authenticated /app is a distinct renderer and is not silently changed.

## Candidate integration

On the research branch only, add `?glass-renderer=continuous` to the public route URL before loading. The default uses the baseline shader. The candidate specializes geometry return precision and normalized UV transport; it replaces the authored icon optical field with the prepared cubic curves and a bounded nearest-point evaluation. The original vector final coverage, haze, material, color, backdrop mip pipeline and interaction code remain. The glyph optical distance is still raster-derived; signed-half native blur research is not imported as an unvalidated material change. The candidate is not approved for default use or deployment.

## Integrated candidate status

The opt-in public candidate now consumes all sixteen authored icon vector controls and replaces the fixed optical distance texture with a bounded BVH Bézier evaluator. It caches only evaluations at exact current framebuffer sample positions and falls back to direct evaluation on unmatched sample phase. The latest A/B owned attachment test has zero cached-versus-direct byte differences at DPR 1 and 2. The existing display-only haze and source mipbox chain are preserved. The reference density is explicitly DPR 2; authored reference-pixel lengths and viewport mip LOD are mapped to the actual density. This preserves the reference material setting, not the inconsistent old 1x optics.

See SITE_VALIDATION.json for 686 passing tests, local Home/Projects smoke tests, numerical output and performance measurements, and outstanding conditions. The high-scale independent field test has not returned a valid result. The Projects heading optical glyph field remains raster-derived. Real sign-in, dynamic interactions, fidelity and full-page performance remain unapproved. No default switch, deployment or Oracle claim is made.
