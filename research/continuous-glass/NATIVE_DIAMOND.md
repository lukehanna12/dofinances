# Recovered variable-blur diamond

The native Clear dispatch and intermediate textures are retained in Oracle PR #55. Native function names, exact uniforms and all bytes of capture plus three mip surfaces are recorded. Independent replay of the installed functions is byte-identical. This is not a global Apple Glass output proof.

The 13 positions are the integer offsets with |x|+|y| <= 2. Weight classes are exact binary16 words: outer axes 2b36, diagonals 2cef, inner axes 2dc6, center 2ec0. Their multiplicity-weighted sum is exactly one. On an even dyadic source, the native sample at each destination center is the half-rounded bilinear interpolation of its corresponding 2x2 input. The observed native arithmetic sums each four-sample group in half precision, starts with a half-rounded center product, then accumulates diagonal, inner-axis and outer-axis products as half FMA. All 4864 even-dimension held-out output channels match byte hashes. Odd-dimension sampler semantics remain open, so the compatibility routine rejects them.

The real-arithmetic extension evaluates the same weighted shifted continuous tent reconstruction, rather than resizing an intermediate mask or fitting a Gaussian. With logical pitch s, the shifts are (2*s_x*a,2*s_y*b). The camera rate and display density are not inputs to that operator. This continuous extension is an architectural choice, not a claim that arbitrary pitches are native states. The experimental GPU kernel is selected with {kernel:"diamond"}; each query must supply diamondStep:[sx,sy]. Ordinary box queries remain unchanged. Native half arithmetic is separately implemented on the CPU; the real-valued GPU path does not claim exact native rounding. No production import or replacement.

## Explicit native mip compatibility route

Oracle PR #56 retains the independent copy matrix and three new live holdouts. The copy stage reads a signed clamp rectangle, half-quantizes texture reads, performs ordered half sums for each 2x2 cell, then applies the same half FMA diamond and RGB-only near-zero threshold. With the captured backdrop and observed ABI fields supplied, four live cases give 11 whole mip textures, and ten independent crop/format cases give 11128 channel values. Clear's no-base route starts on a doubled source pitch at baseOffset+0.5; Regular preserves the unfiltered base on the original pitch. Each subsequent even stage advances origin by half its previous pitch and doubles pitch. fixedMipScenes supplies these fixed-source grids to ContinuousScene with their correct logical coordinate maps. This allows real continuous reconstruction of an explicitly selected native level, without changing source samples when zoom/density changes. There is no universal public parameter selector or exact variable-LOD sampler claim. The native compatibility path rejects odd subsequent mip dimensions.
