# Recovered variable-blur diamond

The native Clear dispatch and intermediate textures are retained in Oracle PR #55. Native function names, exact uniforms and all bytes of capture plus three mip surfaces are recorded. Independent replay of the installed functions is byte-identical. This is not a global Apple Glass output proof.

The 13 positions are the integer offsets with |x|+|y| <= 2. Weight classes are exact binary16 words: outer axes 2b36, diagonals 2cef, inner axes 2dc6, center 2ec0. Their multiplicity-weighted sum is exactly one. On an even dyadic source, the native sample at each destination center is the half-rounded bilinear interpolation of its corresponding 2x2 input. The observed native arithmetic sums each four-sample group in half precision, starts with a half-rounded center product, then accumulates diagonal, inner-axis and outer-axis products as half FMA. All 4864 even-dimension held-out output channels match byte hashes. The original signed-half odd-dimension sampler remains open; the BGRA8 route below supports the tested odd dimensions.

The real-arithmetic extension evaluates the same weighted shifted continuous tent reconstruction, rather than resizing an intermediate mask or fitting a Gaussian. With logical pitch s, the shifts are (2*s_x*a,2*s_y*b). The camera rate and display density are not inputs to that operator. This continuous extension is an architectural choice, not a claim that arbitrary pitches are native states. The experimental GPU kernel is selected with {kernel:"diamond"}; each query must supply diamondStep:[sx,sy]. Ordinary box queries remain unchanged. Native half arithmetic is separately implemented on the CPU; the real-valued GPU path does not claim exact native rounding. No production import or replacement.

## Explicit native mip compatibility route

Oracle PR #56 retains the independent copy matrix and three new live holdouts. The copy stage reads a signed clamp rectangle, half-quantizes texture reads, performs ordered half sums for each 2x2 cell, then applies the same half FMA diamond and RGB-only near-zero threshold. With the captured backdrop and observed ABI fields supplied, four live cases give 11 whole mip textures, and ten independent crop/format cases give 11128 channel values. Clear's no-base route starts on a doubled source pitch at baseOffset+0.5; Regular preserves the unfiltered base on the original pitch. Each subsequent even stage advances origin by half its previous pitch and doubles pitch. fixedMipScenes supplies these fixed-source grids to ContinuousScene with their correct logical coordinate maps. This allows real continuous reconstruction of an explicitly selected native level, without changing source samples when zoom/density changes. There is no universal public parameter selector. The BGRA8 path now supports odd subsequent mip dimensions; signed-half odd subsequent stages are rejected.

## Odd-sized sources

An isolated public Metal sample kernel on the target uses normalized linear sampling at explicit LOD zero and returns half4. Its measured output, with the BGRA byte-lane order corrected, plus the independent half/FMA diamond reproduces 4136 native private-kernel output channels (three odd shapes in two formats). Oracle PR #57 retains 53768 reconstructed half sample lanes losslessly, deduplicated only by identical logical tap position. This narrows the difference to portable sampler modeling: nearest 1/256 fractional coordinate weights and ties-away final half rounding fit many signed half controls but leave six distinct sample-value counterexamples in the 63x31 case. Subsequent Oracle PR #58 resolves the tested BGRA8 counterexamples using q8 ties-up coordinate weights and q4 ties-up encoded-code rounding. Three odd native BGRA8 output hashes are reproduced without captured hardware samples. Signed-half odd dimensions remain open; no global proof has been closed.

Validation: 30 mathematical tests pass, 432 new WebGPU source/color comparisons pass; max source error 1.206e-5, max candidate color error 1.149e-5 on Apple Metal-3. Equivalent density/magnification maps produce identical 1152 tile channel words. The production renderer is not imported or changed.

## Explicit fractional mip sampling

Oracle PR #59 verifies 98,304 native half lanes across eight nonconstant mip chains, including 65,536 independent holdout lanes. The model half-rounds LOD, floors the fractional level to q6, rounds upper q16 tap weights ties upward, and derives lower weights by exact column conservation. Encoded BGRA8 codes are converted to RGBA binary16 lanes after q4 rounding. The integer WebGPU evaluator matches every retained native hash, twice. It does not claim arbitrary signed-half sampling or full Glass shader execution.

The fixed mip field provides two explicit consumers over a common logical source lattice. Continuous reconstruction uses real spatial and level interpolation, including optional footprint integration. Native sampling uses the recovered quantized BGRA8 arithmetic with explicitly supplied LOD. Both preserve the base extent and phase across odd dimensions and camera changes. Color remains normalized encoded UNORM, not a linear-light or display-output claim. The CPU optical reference exposes these as experimental mip modes; the existing integrated optical GPU evaluator still uses box/diamond. The standalone exact WebGPU mip evaluator is verified separately.
