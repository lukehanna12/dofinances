# Continuous backdrop reconstruction

Experimental only. No production import. The canonical input is a fixed source image with logical origin and sample spacing, not a capture at the current display resolution. The piecewise-bilinear reconstruction is integrated analytically over arbitrary axis-aligned box footprints. A sparse tensor product of integrated tent basis terms and a node summed-area table reduces a rectangular footprint query to a bounded number of rectangle sums, independent of footprint size (after source preprocessing). Float64 numerical error is tested against direct full-grid integration; formal interval bounds and large-image cancellation handling remain open. The box kernel is a candidate control, not a recovered native blur kernel. Affine/sheared footprints are not yet covered.

The separate public Metal blit candidate uses center-aligned previous-level sampling, 1/256 quantized weights and half ties-away rounding. This is a finite public API hypothesis only; native sampler general residuals and QuartzCore selection remain open. The finite LOD and mip level controls retain the Oracle's separate selection contracts. No automatic substitution into the production pipeline.
